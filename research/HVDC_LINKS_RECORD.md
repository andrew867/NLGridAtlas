# HVDC link system record

Work item: `HVDC-002`  
Evidence date: 2026-11-11

## Scope

This record supports the atlas diagrams for the Labrador-Island Link and Maritime Link. It separates commissioned operation from earlier filed design material. The diagrams show the supported system interfaces, pole designations, terminal names, ratings, and ground-return facilities. They do not reconstruct breaker positions or claim that preliminary single-lines are current as-built drawings.
